# 스도쿠

입문부터 극한까지 7단계 난이도의 클래식 9×9 스도쿠. 파일 하나(`index.html`)로 동작하고, 외부 데이터 없이 게임마다 문제를 새로 생성한다.

- 난이도: 1~3단계는 처음 보이는 숫자 수, 4~7단계는 풀 때 필요한 기법(교차·페어 → 트리플·X-Wing → Swordfish·XY-Wing → 기법으로 풀리지 않음)으로 판정
- 메모, 되돌리기, 지우기, 힌트(게임당 3회), 타이머, 실수 횟수
- 홈 화면에 추가하면 앱처럼 전체 화면으로 열리고, 한 번 연 뒤에는 오프라인에서도 동작

## 수정 후 배포

1. `index.html` 수정
2. `sw.js` 의 `CACHE` 버전을 올림 (`sudoku-v1` → `sudoku-v2`). 올리지 않으면 이미 설치한 폰에 예전 파일이 계속 표시된다.
3. 커밋 후 `main` 에 푸시하면 GitHub Pages 가 1~2분 안에 반영
